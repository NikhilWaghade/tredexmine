# TreadExMine Development Rules

Before every task:

1. Read PROJECT_STATUS.md
2. Read rules.md

After every milestone:

1. Update PROJECT_STATUS.md
2. Update Progress %
3. Mark completed tasks
4. Add next milestone

Never start a new module until previous module is completed and tested.

Git Workflow:

One feature = One branch

Examples:

feature/project-setup
feature/authentication-foundation
feature/wallet-foundation
feature/plans-module
feature/referral-system
feature/withdraw-module
feature/admin-panel

Commit Style:

feat:
fix:
refactor:
docs:
chore:git
